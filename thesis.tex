This file is a starting point rather than a complete dissertation. The main body is double-spaced, with a 1.5 inch left margin and 1 inch margins on the other sides, matching the guide.

The front matter order implemented here is title page, optional copyright page, optional dedication, optional acknowledgements, abstract, table of contents, list of tables, and list of figures. References appear before appendices.
